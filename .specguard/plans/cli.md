## Summary

Build the `specguard` CLI binary as a pure wiring layer that parses arguments, loads config from `.specguard/config.json` (or a custom `--config` path), and dispatches to pipeline functions. The CLI contains no business logic — it handles argument parsing, config loading, error messaging, and exit codes only. The `init` subcommand scaffolds the config and specs directory; all other subcommands delegate 1:1 to their respective pipelines.

- `src/cli/index.ts` — Main CLI entrypoint — wires argument parsing, config loading, and subcommand dispatch
- `src/cli/args.ts` — Argument parsing logic: --help, --version, --config, and subcommand routing
- `src/cli/config-loader.ts` — Loads and validates .specguard/config.json from cwd or --config path; surfaces actionable errors
- `src/cli/commands/init.ts` — init subcommand: scaffolds .specguard/config.json and specs/README.md if they don't exist
- `src/cli/commands/reverse.ts` — reverse subcommand: thin wrapper that calls the reverse pipeline function

4. 4. Implement `src/cli/help.ts`: top-level usage string listing all subcommands, and a per-subcommand help renderer used when a subcommand is invoked with `--help`.
5. 5. Implement the `init` command in `src/cli/commands/init.ts`: check for existence of `.specguard/config.json` and `specs/README.md`, create them with default content if absent, print confirmation, exit SUCCESS.

7. 7. Implement the `reverse` subcommand wrapper in `src/cli/commands/reverse.ts`: accept parsed args, call the reverse pipeline, propagate its exit code.
8. 8. Build the subcommand registry in `src/cli/commands/index.ts`: a map of subcommand name → handler function covering at minimum `init` and `reverse`.
9. 9. Wire everything together in `src/cli/index.ts`: parse args → if `--version` print version and exit → if `--help` print help and exit → load config (skip for `init`) → look up subcommand in registry (unknown = exit 1 with error message) → dispatch to handler.
10. 10. Create `bin/specguard.ts` as the executable shim (with `#!/usr/bin/env node`) that imports and invokes `src/cli/index.ts`; register it under `bin` in `package.json`.
